TELEGRAM VIDEO BOT — БЫСТРЫЙ СТАРТ

В архиве исходный код бота. Чтобы он появился в Telegram, зарегистрируйте его
у https://t.me/BotFather командой /newbot и запустите этот проект со своим токеном.

ВАРИАНТ 1 — DOCKER (всё окружение устанавливается вместе)
1. Установите Docker Desktop и запустите его.
2. Скопируйте .env.example в .env, откройте .env и вставьте токен после BOT_TOKEN=.
3. В терминале в этой папке выполните: docker compose up -d --build
4. Откройте своего бота в Telegram, нажмите «Запустить» и отправьте ссылку.

ВАРИАНТ 2 — WINDOWS БЕЗ DOCKER
1. Установите Python 3.12, FFmpeg с ffprobe, Node.js 22+ или Deno.
2. Запустите start.bat, вставьте токен в открывшийся .env и сохраните его.
3. Запустите start.bat ещё раз. Оставьте окно открытым.

В README.md есть пошаговые инструкции, ссылки на программы, настройка cookies,
лимиты, запуск на Linux и отправка больших файлов через собственный Bot API.

Команды: /start, /quality, /cancel, /status, /id, /help.

Ссылки проверяются через yt-dlp. Поддерживаются перечисленные площадки и многие
другие, но авторизация, регион и защита сайта могут мешать отдельным загрузкам.
Большие видео по умолчанию отправляются частями до 49 МБ.

Бот работает только пока работает компьютер/сервер с запущенным проектом.
Своим токеном делиться не требуется: добавьте его в .env у себя.
